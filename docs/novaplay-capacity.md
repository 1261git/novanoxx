# NovaPlay 영상 저장·전송 검토 — 2026-10-22

확정: 메뉴 NovaPlay, 1·2화 무료, 3화부터 기본 회당 3 NEON. 회차별 가격 입력은 유지한다. 기존 자료와 원본은 보존한다.

## 현재 운영 자원과 한계

Render MCP 조회: novanoxx, 1인스턴스, 0.5 CPU, 메모리 512MB, /data 디스크 총 5GB. 5GB는 남은 용량이 아니다. MCP 응답에는 현재 디스크 여유 공간과 작업공간 월간 잔여 전송량이 없어 확인했다고 표시하지 않는다. 최근 유휴 상태의 자원 사용량은 동시 영상 재생 성능의 근거가 아니다.

후보 구현은 로컬 디스크의 MP4를 Node HTTP Range로 직접 전송한다. HLS 자동 화질·영상 CDN·트랜스코딩은 없다. 영상 업로드는 비활성이다. 파일당 300MB, 후보 폴더 600MB 상한은 기존 자료를 보호하는 개발 제한이며 전체 5GB를 영상에 사용할 수 있다는 의미가 아니다. 10분 영상 2–4Mbps라면 대략 150–300MB, 10편이면 1.5–3GB가 필요하고 원본 백업은 별도다.

100명 동시 재생은 곧바로 서버 다운을 의미하지 않는다. 다만 2–4Mbps 기준 영상만 200–400Mbps(25–50MB/s), 10분간 15–30GB 전송이다. CPU·디스크·네트워크·업로드·인증 요청이 겹치는 현재 단일 서버로 안정성을 보증할 수 없다. 유료 부하 실험이나 합성 100인 접속은 실행하지 않았다.

## 권장 연결

홈페이지·회원 인증·작품/회차 정보·NEON 시청권은 기존 Render를 유지한다. 크리에이터 영상은 단기 업로드 URL로 전용 스트리밍 서비스에 직접 업로드하고, 처리 완료 웹훅 뒤 공개 가능 상태로 전환한다. 무료 회차도 서비스에서 전송하고, 유료 회차는 서버가 시청권을 확인한 뒤 짧은 만료시간의 서명 토큰을 발급한다. 영상 바이트를 Render로 중계하지 않는다. 별도 일반 웹 서버 추가는 우선 필요하지 않다.

이는 권장 적용안이며 아직 연결한 기능이 아니다. 직접 업로드·처리 상태/웹훅·서명 재생·자막/이어보기 플레이어 연동·비용 제어·복구 경로가 필요하다. 유료 원장·차감·환불·정산도 아직 운영 연결 전이다. 전용 CDN이 영상을 처리하면 영상에 의한 Render 부하는 줄지만, 전체 사이트 동시 100명 성능까지 검증했다는 뜻은 아니다. 서명 재생은 화면 캡처 방지 DRM이 아니다.

세금·환율·추가 버퍼링·기존 Render/DB/메일/백업 요금은 제외한 단순 예상이다. 동시 인원보다 누적 전송 분량이 요금을 결정한다. 무료 1·2화와 재시청도 전송 요금이 발생한다. 3 NEON은 판매 가격이며 원가나 순수익을 보장하지 않는다. 공개 전 업로드 시간/편수 제한, 사용량 알림과 예산 초과 시 차단 정책을 정해야 한다. 알림만으로 확정적인 요금 상한을 보장하지 않는다.

[Render 공식 전송 요금](https://render.com/docs/outbound-bandwidth)은 작업공간 포함량 초과 시 공개 인터넷 $0.15/GB다. 100명×10분의 15–30GB가 전부 초과분이면 $2.25–4.50이며 기존 사이트 사용량은 별도다. 업로드 자체는 무료지만 저장/시청이 무료라는 의미는 아니다. [디스크 공식 가격](https://render.com/pricing)은 GB당 월 $0.25이며 기존 5GB 할당의 디스크 요금은 월 $1.25 상당이다(전체 서버 요금 아님). 작업공간 실제 청구서나 월간 잔여량은 조회하지 않았다.

## 이번 실행 범위

NovaPlay 이름·확정 가격 기록과 개발자노트만 기존 서비스에 배포한다. 새 유료 자원·요금제 변경·업로드/실제 NEON 구매 활성화는 하지 않는다. 기존 R2 백업 버킷은 영상용으로 전환하거나 공개하지 않는다. 전용 서비스 비용 승인 뒤 운영 연결을 구현하고 제한된 실제 파일 1개로 필요한 재생/권한 확인과 백업·복구 범위를 확인한다.
